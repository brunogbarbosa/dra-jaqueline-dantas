# Dra. Jaqueline Dantas

Landing page editorial para a Dra. Jaqueline Dantas, cirurgiã-dentista com atuação em clínica geral, reabilitação oral e estética.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.

## Verificação

```bash
npm run typecheck
npm run build
```

## Deploy na Vercel

O projeto está pronto para importação direta pela Vercel. O framework Next.js e os comandos de build são detectados automaticamente.

## Conteúdo

Identidade, textos, contatos e imagens ficam centralizados em `data/site.ts`. As imagens da profissional e dos resultados estão em `public/images`.

Fontes locais com as respectivas licenças em `public/fonts`. O favicon vetorial usa o monograma JD na paleta carvão, marfim e champagne.
